# Zachary Xue's Blog

基于 [Astro](https://astro.build) 搭建的个人博客，托管于 GitHub Pages。

## 博客定位

记录生活与工作中的思考，主要涵盖三个方向：

- **炒股笔记** — 用真金白银换来的市场教训，比任何教科书都深刻
- **读书笔记** — 文学、历史、技术、投资，读到哪记到哪
- **技术笔记** — 关注 CI/CD、服务架构、容器集群、AI，学习与排坑的实战总结

## 技术栈

- **框架**: Astro v5
- **内容**: Markdown + Content Collections
- **部署**: GitHub Actions → GitHub Pages

## 本地开发

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # 构建到 dist/
npm run preview    # 预览构建结果
```
