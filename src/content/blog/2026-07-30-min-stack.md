## 问题

实现一个栈，支持 `push`、`pop`、`top`、`getMin` 四个操作，**全部 O(1)**。

## 思路

单栈只能 O(1) 完成 push/pop/top。getMin 要 O(1)，必须在每次 push 时就把"当前最小值"记录下来，pop 时同步扔掉——**辅助栈同步追踪**。

- **主栈 `stack`**：正常存值
- **辅助栈 `min_stack`**：存**每一步**对应的最小值
- 两个栈高度始终一致，同进同出

push 时：`min_stack` 压入 `min(新值, min_stack 栈顶)`。pop 时两个栈一起弹。`getMin` 直接读 `min_stack[-1]`。

## 实现

```python
class MinStack:
    def __init__(self):
        self.stack = []      # 主栈存值
        self.min_stack = []  # 辅助栈存每一步的最小值

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.min_stack:
            self.min_stack.append(val)
        else:
            self.min_stack.append(min(val, self.min_stack[-1]))

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def get_min(self) -> int:
        return self.min_stack[-1]
```

## 推演

```
push(5)   stack=[5]       min_stack=[5]       min=5
push(3)   stack=[5,3]     min_stack=[5,3]     min=3  ← 3<5，更新
push(7)   stack=[5,3,7]   min_stack=[5,3,3]   min=3  ← 7>3，沿用
push(2)   stack=[5,3,7,2] min_stack=[5,3,3,2] min=2  ← 2<3，更新
pop()     stack=[5,3,7]   min_stack=[5,3,3]   min=3  ← 2走了，自动恢复
```

pop 掉 2 后，`min_stack` 同步弹出，栈顶回到 3，最小值自动恢复——不需要重新扫描。

## 复杂度

| 操作 | 时间 | 空间 |
|------|------|------|
| push | O(1) | O(n) |
| pop | O(1) | — |
| top | O(1) | — |
| getMin | O(1) | — |

## 空间优化

当连续 push 较大值时（如上面的 5→3→7），`min_stack` 会存重复的最小值（3 出现了两次）。可以用 **(val, count)** 只在最小值变化时记录：

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []  # [(min_val, count)]

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.min_stack or val < self.min_stack[-1][0]:
            self.min_stack.append([val, 1])
        elif val == self.min_stack[-1][0]:
            self.min_stack[-1][1] += 1

    def pop(self) -> None:
        val = self.stack.pop()
        if val == self.min_stack[-1][0]:
            self.min_stack[-1][1] -= 1
            if self.min_stack[-1][1] == 0:
                self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def get_min(self) -> int:
        return self.min_stack[-1][0]
```

连续 push 相同值时会复用计数，push 大于当前最小值的元素不占 `min_stack` 空间。复杂度不变，但在递减序列较多的场景能省不少内存。
