## 一句话本质
**博弈型 DP 的完整套路**：四个信号识别（最优性/轮流最优/顺序结构/无后效性）→ 暴力递归加 `lru_cache` 验证重叠子问题 → 差值法状态「当前玩家比对手多拿多少」→ 转移「我这轮拿的 − 对手最优」→ 最后 (差值 + 总和)/2 还原先手总数；零和博弈中「你多就是我少」使差值法天然最简。

## 触发判据（四信号全中即博弈 DP）

| 信号 | 内容 |
|---|---|
| ① | 求最优/最大/最小 |
| ② | 轮流出招且都发挥最佳水平 |
| ③ | 元素排成一行、位置可作状态 |
| ④ | 决策只依赖当前状态（无后效性） |

## 方法要点

- **判定捷径**：先写暴力递归，加 `@lru_cache` 后若瞬间变快，说明重叠子问题密集 → 这就是 DP；记忆化搜索本身就是自顶向下 DP，不必填表。
- **状态设计**：状态 = (当前位置 i, 当前限制参数 m)；博弈题天然多一个「站在当前玩家的视角」，差值描述可消去「轮到谁」的维度。
- **差值法转移**：`dfs(i,m) = max{ 区间和(我这轮拿的) − dfs(i+x, max(m,x)) }`——「我这轮拿的」减去「对手后续比我多拿的」= 我比对手多拿的；前提是零和博弈、总和固定。
- **答案还原**：差值法返回值是当前玩家优势，(差值 + 石子总和)//2 还原为先手总石子数；整数性来自差值 = 2x − sum 恒同奇偶。
- **两种定义对比**：总数法（sumRest − min{子问题}）直接产出总数但转移略绕；差值法转移最简洁，推荐优先。
- **三件套口诀**：前缀和（O(1) 区间和）+ 记忆化（lru_cache）+ 枚举合法选择 → 递归 → max；固定边界（拿完/能一次拿完）。

## 记住点
双方轮流 + 最优策略 + 排成一行：套差值法博弈 DP——前缀和 + 记忆化 +「我这轮拿的 − 对手最优」。
