## 一句话本质
**单调队列 = 普通队列管窗口内容/和 + 单调递减队列管最值**：入队前先弹出所有被新值「压过」的队尾候选（新值无条件入队），队首恒为窗口最大值；每个元素只入队一次、出队至多一次 → 均摊 O(1)。

## 方法要点

- **结构分工**：普通队列保留窗口全部元素（算 sum/平均值），单调队列只保留「有价值候选」管 max——双结构协作，每次 add 均摊 O(1)。
- **入队铁律**：新值无条件入队；入队前 `while` 弹掉所有比它小的队尾——小值现在不是最大，但大值过期后要它接班，丢了队列就断（最致命 bug）。
- **头尾方向**：单调递减队列队首 = 最大值，取 max 读 mono[0]；元素过期时判断 `mono[0] == 弹出的旧值` 再 popleft——头尾搞反是高频致命 bug。
- **相等值用 < 不用 <=**：<= 会破坏「值→元素」一一对应，过期判断产生歧义误弹；最稳做法是存下标，过期判断改为 `mono[0] < i − window + 1`，彻底绕开相等歧义。
- **复杂度论证**：每元素入队恰一次、出队至多一次（被单调性淘汰或过期弹出），n 个元素总 O(n) → 均摊 O(1)，空间 O(window)。

## 通用思维链（怎么想到单调结构）

1. 先写一定对的暴力枚举；
2. 找出暴力里「反复往回扫」的子操作（找左右第一个更大/更小）；
3. 识别成 next greater/smaller 模式；
4. 单调结构 + 弹栈结算换均摊 O(1)。

**触发判据清单**：对每个元素要「左/右第一个比它大或小」/ 一维有序结构 / 朴素做法 O(n²) 味道 / 候选后进先结算（LIFO）——命中即单调栈。

**家族映射**：next greater → 单调递减栈弹栈结算；next smaller → 单调递增栈；窗口最值 → 单调队列；84 柱状图弹栈结算区间面积；862 前缀和 + 单调递增队列（淘汰规则随语义重推）。

## 记住点
滑动窗口要实时最值就上单调队列：新值先弹光比自己小的队尾再无条件入队，过期只判队首；相等值用 < 不用 <=，最稳存下标。
