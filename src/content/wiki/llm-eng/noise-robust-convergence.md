## 一句话本质
**从噪声数据里判断"真实信号"（如某商品的策略是否已收敛）时，正确姿势不是提高覆盖率，而是层层过滤掉不可信样本 + 用组合抵消个体噪声 + 只留高精度小集合——"宁可大量样本不进结论，也不让不可信数据污染结论"。**

## 问题形态（判断"收敛"）

场景：模型持续为大量对象产出策略并周期性迭代，「收敛」= 某个对象的策略已稳定跑出可信的正向结果，可固定下来不再迭代。核心问题只有一个：

> **这个正向结论是真实的，还是数据噪声造成的假象？**

两个难点：

| 难点 | 表现 | 为什么致命 |
|------|------|-----------|
| 单日数据不可信 | 策略没变，今天 +20%、明天 -15% | 是随机波动，不是策略在变 |
| 样本量差异极大 | 头部日成交巨大，长尾一周 2 单 | 少 1 单 = 50% 跌幅，统计上无意义 |

## 解法：四层漏斗

```
全量样本
   │ Layer 1 量级过滤（低成交量/零销/数据缺失）      ➜ 滤掉约九成
   ▼
有效样本
   │ Layer 2 时间一致性（连续多天方向一致）          ➜ 再滤掉约八成
   ▼
稳定样本
   │ Layer 3 稳定性评分（贝叶斯收缩 + 趋势 + 综合）   ➜ 取头部少量
   ▼
高分样本
   │ Layer 4 组合口径验证（贪心选择 + 组合逐日验证）
   ▼
clean_set（最终收敛集合）
```

### 两个关键设计

- **贝叶斯收缩**：数据天数越少，评分越保守、越向"行业平均水平"靠拢——不会因为"恰好少数几天表现好"就给高分（把样本量不足自动降权）
- **组合才可信**：单个样本的结论可能是噪声，把多个样本组合起来看，**个体随机噪声在组合层面相互抵消**（原文类比投资组合分散风险）。实现：从贡献最高的样本开始逐个加入，每加一个就验证组合后**每一天**的指标是否仍全部达标，不达标则跳过，直到无法继续加入

## 与 Rubric 筛选是同构的

| 环节 | Rubric 筛选 | 收敛判断 |
|------|------------|---------|
| 稳定性筛选 | 200 次 Bootstrap 只留高频入选的准则 | 时间一致性 + 稳定性评分只留方向稳定的样本 |
| 组合验证 | 交叉验证贪心，逐条加入并验证整体 | 贪心组合，逐个加入并验证组合逐日达标 |
| 收口原则 | 宁可部分偏好无法判断 | 宁可大量样本不进 clean_set |

同一个骨架：**稳定性筛选 → 贪心组合 → 高精度优于高覆盖**。

## 记住点

**精度是能守住的，覆盖率可以放弃**——先问"这批数据里哪些可信"，再回答业务问题；反过来（先要覆盖，再补可信度）一定被噪声牵着走。
