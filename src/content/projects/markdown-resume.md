Markdown 驱动的个人简历系统：以 Markdown 为唯一内容源，一键生成 HTML / PDF。Python-Markdown 渲染 + 自定义 CSS 排版，支持按目标公司维护多份简历变体（脚本参数切换），适合程序员长期维护的极简简历方案。

简历内容为个人隐私，**本站不展示真实简历**，仅提供仓库链接。

> 📄 完整源码与使用方式：[GitHub 仓库](https://github.com/ZacharyXue/Markdown-Resume)
